# Royal Fitted Wardrobe — Project Plan

## 1. Project plan

- Goal: Build a premium, responsive business website inspired by [Golden Fitted Wardrobe](https://goldenfittedwardrobe.co.uk/), with original branding and content.
- Confirmed frontend: HTML5, CSS3 and vanilla JavaScript.
- Proposed CMS: Sanity.
- Proposed hosting: Cloudflare Pages.
- Expected traffic: 2,000 visitors/month.
- Estimated running cost: £10–£15/year for domain only, subject to pricing and free-tier limits; excludes email and paid support.
- Owner has no coding knowledge. Provide a secure dashboard to add/remove photos and update phone numbers, email and social media links.
- Priorities: responsive design, SEO, accessibility, security, optimised images and simple maintenance.
- Do not start coding or modify repository files without explicit user approval.
